# Лабораторна робота №2 (Java)

Соловійщук Назар Олексійович, група ІО-45

## Що в репозиторії

- `simple-task` - Simple Task, завдання 2.1: клас `Person` з методом `equals`, перетворення в JSON і назад
- `hard-task` - Hard Task: власні `MyArrayList` і `MyLinkedList`, `MyLinkedHashSet` та кеш

Обидва проєкти зібрані через Maven.

## Simple Task (2.1)

Клас `Person` має поля прізвище, ім'я і вік. Для нього я написав `equals` та `hashCode`.
У `Main` створюється об'єкт, за допомогою Gson він перетворюється в JSON, потім
повертається назад в об'єкт, і початковий та отриманий об'єкти порівнюються через `equals`.

Для `equals` є unit-тест на EqualsVerifier (`PersonTest`).

## Hard Task

- `MyList` - інтерфейс з методами з завдання (`add`, `addAll`, `get`, `remove`, `set`, `indexOf`, `size`, `toArray`)
- `MyArrayList` - реалізація на масиві, підтримує маркерний інтерфейс `RandomAccess`
- `MyLinkedList` - реалізація на двозв'язному списку
- `MyLinkedHashSet` - множина без повторів, яка пам'ятає порядок додавання. Всередині хеш-таблиця
  і двозв'язний список, готові класи колекцій не використовуються
- `MyCache` - кеш на основі LRU: коли місця немає, видаляється запис, яким найдовше не користувались.
  Записи також застарівають за часом, а `null` не можна використовувати ні як ключ, ні як значення

На все є unit-тести (JUnit 5).

## Як запустити

Відкрити потрібну папку (`simple-task` або `hard-task`) в IntelliJ IDEA як проєкт.
`Main` у `simple-task` запускається звичайно. Тести запускаються з папки `src/test/java`
через Run 'All Tests'.
